# Provenance

pio2 was split out of [AbstractX](https://github.com/tcmichals/AbstractX) on 2026-10-29. The PIO
block was developed there from `4675e3b` (2026-10-25, first quad-SM tile) to `559022f`
(2026-10-27, last PIO change; 10 commits). Files were copied from AbstractX `4289a95`; their
history stays in AbstractX (`git log -- rtl/pio`).

| pio2 | AbstractX (before the split) |
| :--- | :--- |
| `src/rtl/asp_pio_sm.sv`, `asp_pio_tile.sv`, `asp_pio_tlp_ingress.sv`, `asp_pio_tlp_shim.sv` | `rtl/pio/` |
| `src/programs/` | `rtl/pio/programs/` |
| `docs/SPECIFICATION.md` | `rtl/pio/SPECIFICATION.md` |
| `docs/architecture.md` | `rtl/pio/README.md` |
| `src/pio2/programs.py` | `tools/pio_programs.py` |
| `src/pio2/examples.py` | `tools/pio_examples.py` |
| `src/pio2/dshot_ref.py` | `tools/dshot_ref.py` |
| `tests/cocotb/test_asp_pio_*_cocotb.py` | `sim/cocotb/` (same names) |
| `LICENSE` | `LICENSE` (GPL-3.0) |

Third-party content:

* `src/programs/examples/pico/`: `.pio` programs from Raspberry Pi
  [pico-examples](https://github.com/raspberrypi/pico-examples), BSD-3-Clause, with their
  `LICENSE.TXT`. The assembled `.json` images next to them are generated by `pioasm`.
* No Raspberry Pi documentation is stored here; see [references.md](references.md).

`tests/cocotb` 39/39 pass (tile 5, conformance 19, DShot 5, ESC serial 3, TLP path 7), the same
tests that pass in AbstractX.
